# Alex & Oscar BuyTrigger — Card Desk

First public edition · 3 November 2026. Free card news, collecting guides and the TCG Modern Index research beta.

Website: https://dralexkoh.github.io/buytrigger-card-desk/

This repository contains the public static website only. Personal holdings, costs, photographs, owner analytics and authentication data are excluded.

## Current scope

- Ten source-linked illustrated articles, six short news updates, direct story pages and RSS.
- 90 exact modern card identities with 87 dated Raw references via TCGCSV. Graded provider data and card photographs await public-use clearance. Original research graphics identify each card; source links open the original artwork and evidence.
- Three-outcome grading calculator. Top 50 and complete index history remain in development.
- No membership, active ads, affiliate programme or visitor tracking. Revenue integrations and the custom domain follow separately.
